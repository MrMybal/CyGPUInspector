# Référence clavier et navigation

## Le contexte compte
| Touche/action | Contexte | Effet |
| --- | --- | --- |
| F1 | Application | Ouvrir l’aide de la vue active |
| F5 | Espace de travail, hors éditeur/saisie | Actualiser les connexions |
| Ctrl+S | Espace de travail, hors éditeur/saisie | Sauvegarder la frame |
| F7 | Éditeur HLSL actif | Compiler sans remplacer |
| F5 | Éditeur HLSL actif, session en direct | Compiler et injecter |
| Ctrl+O | Éditeur HLSL actif | Ouvrir un fichier source |
| Ctrl+S | Éditeur HLSL actif | Sauvegarder la source dans un fichier |
| Ctrl+Z / Ctrl+Y | Éditeur HLSL actif | Annuler / rétablir le texte |
| Ctrl+F | Éditeur actif | Rechercher/remplacer |
| Ctrl+A | Éditeur actif | Tout sélectionner |
| Ctrl+Entrée | Saisie du chat IA | Envoyer la requête |
| Ctrl+K | Fenêtre d’aide active | Activer la recherche dans les articles |
| Molette / glisser | Timeline ou image | Zoomer / déplacer |
| Double-clic / Ajuster | Vue de temps | Restaurer la plage utile |

F5 a deux sens : l’éditeur actif possède le raccourci compiler/appliquer ; l’actualisation du workspace ne doit pas intercepter la saisie. Utilisez les boutons si le focus est incertain. Une action grisée signale un état en direct manquant ou une autre condition, pas un besoin d’augmenter des droits sans rapport.

## Naviguer dans l’aide
Choisissez un sujet dans l’index ou cherchez des mots de son texte. Les deux langues conservent le même identifiant de sujet. Le sommaire et les liens de section ouvrent un titre ; Précédent/Suivant du navigateur et les outils CyDoc retrouvent la lecture. Images et SVG statiques sont intégrés à l’article. L’agrandissement reste dans la fenêtre ; Échap revient à la lecture. Ces actions ne changent aucun état du jeu.

## Retrouver le workspace
Affichage > Panneaux active un panneau masqué. Réinitialiser la disposition rétablit le layout initial lorsque vous le voulez ; cela ne réinitialise pas captures, base, profils ni historique du texte.
